**Вариант 1 (краткий, для вставки в список планов):**

• **Запуск BEST PR System** — внутренняя веб-платформа и Telegram-бот для PR-отдела: автоматизация рутинных процессов, прозрачность работы, централизованная коммуникация. Дополнительно: лента событий (Timeline), уведомления в боте и на сайте, лидерборд. Для отдела — снижение нагрузки на координаторов, прозрачный учёт заявок и сроков, меньше «забытых» возвратов. В первом полугодии проект не анонсировался; планируется презентовать LBG и ввести в штатный режим во втором полугодии.
